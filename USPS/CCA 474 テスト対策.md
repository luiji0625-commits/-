## 目標
70点で合格だが、採用は点数の高い順に決まる。**目標は上位スコア**。

## 全パート共通の判断軸
1. **安全 ＞ ルール ＞ お客様 ＞ スピード**
2. 迷ったら supervisor（上司）に報告・相談
3. 自分の判断でルールを曲げない・近道しない
4. ミスは隠さず、すぐ正直に報告

## ① Work Scenarios（場面判断）
- 最も効果的（most effective）な行動を選ぶ
- ワーストになりやすい行動：危険行為、言い返す、黙って配達を飛ばす、ミスを隠す、指示を無視する
- 例：
  - 放し飼いの犬 → 入らない・手順どおりに対応・上司に報告
  - 怒っているお客様 → 丁寧に聞く・窓口を案内
  - ルートが遅れる → 早めに上司に連絡
  - 液体が漏れている荷物 → 配達せず隔離して上司に報告
  - 猛暑でめまい → 日陰で休む・水分補給・上司に連絡
  - ブレーキの異常 → 報告して運転しない

## ② Describe Your Approach（性格）
- 同じ内容が裏返しの言い方で繰り返し出る → **答えをブレさせない**
- 強く同意：時間を守る / 見られていなくてもルールを守る / 冷静 / 屋外の仕事が好き / 一人で働ける / 安全はスピードより大事 / ミスを見直す / 体力がある
- 強く反対：遅刻する / 時間短縮のためならルールを破る / すぐイライラする / 仕事を途中で投げ出す / いつも指示が必要
- 真ん中寄りの回答（Agree / Disagree）ばかりにしない

## ③ Check for Errors（住所照合）
- 選択肢：A No Errors / B Address Only / C ZIP Code Only / D Both
- スピードと正確さの両方が採点される。当てずっぽうはしない
- 見落としやすいポイント：番地の数字の入れ替え、方角（N/S/E/W）、略語（St/Ave/Rd/Dr/Ln/Blvd）、通り名の1文字違い、ZIPの真ん中の数字
- 見る順番を固定する：**住所 → ZIP**
- 練習目標：正答率95%以上、1分あたり8問以上

## ④ Tell Us Your Story（経歴）
- 正直に答える。盛らない（後で確認されることがある）
- 日本での職歴・アルバイト・接客・体力仕事も経験として数える
- 遅刻や欠勤が実際に少ないなら「ほとんどない」と答える
