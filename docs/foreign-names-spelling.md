# 外国人の名前:聞いた音からスペルを推測するガイド

## 1. そもそも何が起きているのか(根本原因)

カタカナの「マイク」は**音を写しただけ**で、スペルとは何の関係もない。
英語のスペルは表音文字ではなく、**歴史的な綴りのルール**に従っている。

```
発音: /maɪk/ (マイク)
   ↓ 英語の綴りルールに変換
スペル: M-I-K-E
```

ポイントは、日本語の頭の中で「マ・イ・ク」と音節ごとに変換しようとすると
永遠にスペルにたどり着けないということ。英語は「音素(発音のパーツ)」と
「綴りパターン」で対応させる必要がある。

## 2. なぜ MIKE なのか:silent e ルール

英語には「単語末尾が `子音+e` だと、その前の母音がアルファベット読み(長母音)になる」
というルールがある。

| 綴り | 読み方 | 例 |
|---|---|---|
| i + 子音 + e | アイ /aɪ/ | m**i**k**e** (マイク), l**i**k**e**, b**i**ke |
| a + 子音 + e | エイ /eɪ/ | d**a**v**e** (デイブ), J**a**k**e** |
| o + 子音 + e | オウ /oʊ/ | J**o**h**e** はないが r**o**se, h**o**pe |
| u + 子音 + e | ユー /juː/ | J**u**n**e** |

`Mike` は `M + i + k + e`。最後の `e` は発音されない(silent e)が、
その `e` があることで直前の `i` が「イ」ではなく「アイ」と読まれる。
`e` を取った `Mik` だと「ミク」に近い読みになってしまう。

## 4. 愛称(ニックネーム)が元の名前と音が違う例に注意

規則から外れて覚えるしかない代表例:

| 愛称 | フルネーム |
|---|---|
| Bob | Robert |
| Bill / Will | William |
| Dick | Richard |
| Jack | John |
| Peggy | Margaret |
| Ted / Ned | Edward |
| Hank | Henry |
| Chuck | Charles |

これは英語ネイティブでも「なぜそうなるか」を説明できない歴史的な慣習。
パターンではなく単純に対応表として覚える。

## 5. 実践:聞いた場で確認する方法

一番確実なのは推測せず本人に聞くこと。仕事の場でそのまま使える定型フレーズ:

- `How do you spell your name?`(スペルを教えてください)
- `Could you spell that for me?`(それをスペルで言ってもらえますか)
- `Is that spelled with a "C" or a "K"?`(C ですか K ですか、迷った時)

相手がスペルを1文字ずつ言うとき、聞き取りやすくするために
フォネティックアルファベット(NATO表記)を知っておくと役立つ:

```
A = Alpha    H = Hotel     O = Oscar    V = Victor
B = Bravo    I = India     P = Papa     W = Whiskey
C = Charlie  J = Juliett   Q = Quebec   X = X-ray
D = Delta    K = Kilo      R = Romeo    Y = Yankee
E = Echo     L = Lima      S = Sierra   Z = Zulu
F = Foxtrot  M = Mike      T = Tango
G = Golf     N = November  U = Uniform
```

余談だが、この表の `M = Mike` は偶然ではなく、まさに今回の "マイク" と
同じ単語。フォネティックアルファベットでも人名の Mike がそのまま採用されている。

## 6. 今後の学習の進め方

1. 職場で聞いた名前を都度この表に追加していく
2. 「音 → 綴りルール → 実例」の順で1つずつ理解する(丸暗記より効率的)
3. 迷ったら遠慮なく `How do you spell that?` と聞く(ネイティブも聞き返す)
