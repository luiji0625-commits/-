# 作業前・作業後チェックリスト

チートシートの「開発チェックリスト」を、この repo の現状（コード無し・1人）に合わせて削ったもの。
項目を足すときは `docs/adoption.md` の「次に採る」から昇格させる形にする。

## 依頼する前（人間側）

- [ ] 目的を1文で言えるか（何のために / 誰のために）
- [ ] 成功条件を書いたか（これが満たされれば完了、と言える条件）
- [ ] 出力形式を指定したか（ファイル / 表 / 箇条書き / 文字数）
- [ ] 前提とコンテキストを渡したか（既存ファイル、制約、参考資料）
- [ ] 承認が要る操作が含まれるか（外部送信・公開・課金・削除）

## 出来上がった後（レビュー）

- [ ] 成功条件を満たしているか（雰囲気ではなく条件と照合する）
- [ ] 検証の跡があるか（どう確かめたかが書いてあるか）
- [ ] 出来なかった部分が明示されているか（黙って縮めていないか）
- [ ] 事実の裏付けがあるか（推測を断定で書いていないか）
- [ ] 決定事項が `docs/` に残ったか（チャットに置き去りにしていないか）

## コミット前

- [ ] 1コミット1トピックになっているか
- [ ] コミットメッセージに「何を」だけでなく「なぜ」があるか
- [ ] 秘密情報（鍵・トークン・個人情報）が入っていないか
