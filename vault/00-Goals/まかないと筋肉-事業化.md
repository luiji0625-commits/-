# まかないと筋肉 — 事業化

## 1. 目標を知る

- 運営中のコンテンツ「まかないと筋肉」（筋トレ×食事/まかない飯ジャンル、現在はX中心）を事業化する。
- 達成したいこと:
  - 収益化（マネタイズ）
  - 発信を仕組み化して継続させること自体（属人的な自転車操業から抜ける）
- 期間感: 半年〜1年で最初の成果を見たい。

## 2. 問題を許容しない

- そもそも伸びていない（ほぼ毎日投稿しているのに反応が薄い）
- ※当初「一人で手が回らない」も障害として挙げたが、実際は既存のCODEX連携が
  投稿文・ネタ・リプライ・分析を担っており、うまく回っている（本人談）。
  診断が変わったので3.で修正する。

## 3. 根本原因を診断する

- 問題: 伸びていない
  - なぜ？ → 投稿がテキスト中心
  - なぜテキスト中心のまま？ → 「まかない飯×筋肉」は本来ビジュアル（写真・動画）で伸びるジャンルなのに、撮影・画像編集に割く時間がない
  - もう一段: なぜ時間がない？ → CODEXが担えるのは文章生成・リプライ・分析までで、調理・撮影という物理作業は本人しかできない

- 当初「投稿文作成・ネタ考え・リプライ対応で手が回らない」を問題としたが、
  これは**すでにCODEXとの連携で解決済み**（本人評価: うまく回っていて、これを軸に伸ばしたい）。
  過去の課題を現在の課題として扱わない（見て見ぬふりの逆＝解決済みを未解決扱いしない）。

**根本原因の再診断**: テキスト生成・リプライ・分析はCODEXが解決している。残る唯一の
ボトルネックは、CODEXが代行できない物理工程＝撮影（ビジュアル素材づくり）。
ジャンルの強み（ビジュアル）を発揮できていないのは、素材そのものが無いから。

体制:
- **CODEX** … X運営の日々の実務（投稿文・ネタ・リプライ・分析）を担当。うまく機能しているので変更しない。
- **Claude Code（このvault）** … 事業全体の計画・Goal管理・意思決定の記録を担当。日々の投稿作業には介入しない。
- **本人** … 調理・撮影・トレーニングという、代行できない物理工程を担当。

素材状況: 撮影・画像動画の素材はほとんどない（現状ゼロ。今まで撮ってこなかった）。
撮らなかった理由を2段階で深掘り:
1. 「面倒」→ 撮る行為そのもの（手が汚れている・作業中の中断）
2. さらに掘ると、本当のネックは**撮るその瞬間に「これで良いのか」と自分で
   評価してしまう恥ずかしさ**（料理・自分が写ることに自信がない）だった。
   物理的な手間ではなく、撮影と評価が分離できていないことが根本原因。

**最終決定（2026-09-18）**: 撮影と評価の分離策は採用せず、**このアカウントでは
自分が撮ったもの（自分の顔・体はもちろん、自分が作った料理の写真も含めて）を
一切使わない方針**にする。恥ずかしさという心理的コストを払い続けてまで自分で
撮る道は選ばない、という意思決定。→ ビジュアルは自分以外の手段（AI生成画像・
図解・素材）で補う方向に計画を作り直す。

希望するマネタイズ手段: 自社商品/コンテンツ販売、アフィリエイト/広告、個別コンサル/コーチング。

## 4. 計画を設計する

### Phase 1（今週〜2週間）: 自分以外のビジュアルで補強する型を作る
- [ ] 「まかないと筋肉」のトーンに合うAI生成画像・図解のスタイルを決める
  （例: 栄養素の図解、筋トレ×食事のTipsカード、レシピの手順図解など、
  実写の代わりになる視覚要素）
- [ ] そのスタイルを`vault/03-Frameworks/`にルール（skill）として固定化し、
  毎回同じ判断基準で作れるようにする
- [ ] CODEXが投稿文と一緒にビジュアル案（AI生成 or 図解）まで作れるか、
  本人がCODEX側に相談・依頼する（実際の生成・運用はCODEX側に委ねる。
  Claude Codeは方針決定までを担当し、日々の生成作業には介入しない）
- [ ] AI生成画像の商用利用・Xでの表示に関する規約面を一度確認しておく

### Phase 2（1ヶ月目〜）: 計画層でのモニタリング
- [ ] 月1回、CODEX側の分析結果（伸びた投稿・伸びなかった投稿、ビジュアル方針が
  効いているか）をこのゴールノートに要約・反映する
- [ ] 自分撮影なし方針で息切れしていないか（規約変更・費用面など）をここで振り返る
- [ ] Claude Codeはあくまで計画・進捗の把握役に徹し、CODEXの運用フローには重複して手を出さない

### Phase 3（3ヶ月目〜）: マネタイズの土台
- [ ] 自社コンテンツ（例: まかないレシピ集、筋トレ×食事の有料note）の企画
- [ ] アフィリエイト導線（プロテイン・調理器具など）の設置
- [ ] 個別コンサル/コーチングの提供設計とフォロワーへの導線

### Phase 4（半年〜1年）: 検証と拡大
- [ ] どの収益源が実際に機能したかを検証し、伸びたものに注力先を絞る
