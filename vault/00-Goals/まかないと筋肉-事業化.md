# まかないと筋肉 — 事業化

## 1. 目標を知る

- 運営中のコンテンツ「まかないと筋肉」（筋トレ×食事/まかない飯ジャンル、現在はX中心）を事業化する。
- 達成したいこと:
  - 収益化（マネタイズ）
  - 発信を仕組み化して継続させること自体（属人的な自転車操業から抜ける）
- 期間感: 半年〜1年で最初の成果を見たい。

## 2. 問題を許容しない

- そもそも伸びていない（ほぼ毎日投稿しているのに反応が薄い）
- 一人でやっていて手が回らない（投稿文作成・ネタ考え／リプライ対応に一番時間を取られている）

## 3. 根本原因を診断する

- 問題: 伸びていない
  - なぜ？ → 投稿がテキスト中心
  - なぜテキスト中心のまま？ → 「まかない飯×筋肉」は本来ビジュアル（写真・動画）で伸びるジャンルなのに、撮影・画像編集に割く時間がない
  - もう一段: なぜ時間がない？ → 一人で全工程（調理・撮影・編集・投稿文・リプライ）をやっている

- 問題: 一人で手が回らない
  - 一番時間を食っている作業: 投稿文作成・ネタ考え、リプライ・フォロワー対応
  - なぜ時間を食う？ → 毎回ゼロから考えている（ネタのストック・返信の型がない）
  - もう一段: なぜ型がない？ → 事業を始めたばかりで、コンテンツの型（フォーマット・投稿設計図）を作っていない

**根本原因はひとつに収束する**: 「毎回ゼロから考える」やり方のまま、工数の低いテキストで
回している。ジャンルの強み（ビジュアル）を活かせず、時間の余裕もない。

素材状況: 撮影・画像動画の素材はほとんどない（ゼロから作る必要あり）。
希望するマネタイズ手段: 自社商品/コンテンツ販売、アフィリエイト/広告、個別コンサル/コーチング。

## 4. 計画を設計する

### Phase 1（今週〜2週間）: 型を作る
- [ ] 投稿ルールを明文化する（トーン・構成・NGワード・ハッシュタグ）→ `vault/03-Frameworks/` にスキルとして固定化
- [ ] 直近1ヶ月分のネタを一気にブレストしてリスト化 → `vault/02-Notes/まかないと筋肉-ネタストック.md`
- [ ] 「まかないを作る/食べるたびに最低○枚撮る」撮影ルーティンを決める（素材ゼロ問題への対処）

### Phase 2（1ヶ月目〜）: 投稿の仕組み化
- [ ] loop: 週1回、直近の反応が良かった投稿を振り返り、来週のネタ候補を出す定例を作る
- [ ] 分業: 本人は「調理・被写体・撮影」に専念し、Claude Codeに「下書き作成・構成案・リプライ文の下書き」を任せる
- [ ] hook: 投稿前チェック（誤字・著作権・炎上ワード）を毎回通す

### Phase 3（3ヶ月目〜）: マネタイズの土台
- [ ] 自社コンテンツ（例: まかないレシピ集、筋トレ×食事の有料note）の企画
- [ ] アフィリエイト導線（プロテイン・調理器具など）の設置
- [ ] 個別コンサル/コーチングの提供設計とフォロワーへの導線

### Phase 4（半年〜1年）: 検証と拡大
- [ ] どの収益源が実際に機能したかを検証し、伸びたものに注力先を絞る
